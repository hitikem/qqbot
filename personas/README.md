# 人格库

一套即插即用的 QQ Bot 人格。每个文件覆盖到 `agent/AGENTS.md` 即生效（热加载，不用重启）。

## 怎么用

```powershell
# 切到某个人格
Copy-Item D:\ds\qqbot-repo\personas\御姐.md D:\ds\qqbot\agent\AGENTS.md -Force
```

> ⚠️ **注意**：`patch.yml` 里的 `persona` 段是主控，优先级更高。
> 如果只换 `AGENTS.md`，实际效果会叠加。想完全切换，建议把 `patch.yml` 的 `persona` 段删掉或同步修改（见文末）。

## 一键切换

```powershell
# 看有哪些
.\set-persona.ps1

# 切换
.\set-persona.ps1 御姐
```

脚本会：
1. 备份当前人格
2. 复制新人格到 `agent/AGENTS.md`
3. **自动把 `patch.yml` 的 persona 段改成中性占位**，确保 AGENTS.md 生效

不用重启，下条消息就变。

## 写人格的模板

每个文件都遵循这个结构，你可以照着自己写：

```markdown
# 人格名 · 一句话定位

## 你是谁
（3-5 行，说清楚这个人是什么身份、什么性格底色）

## 说话方式
（句式、用词、标点习惯、会不会用脏话/颜文字）

## 核心特点
（3-5 条，这个人的行为逻辑）

## 具体表现
（4-5 条，遇到什么情况会怎么反应）

## 尺度 / 边界
（如果有敏感内容，写清楚界限在哪）

## 绝对不做
（硬性红线）

## 例子
我：xxx
你：xxx
```

**关键经验**：
- **例子比描述有效 10 倍**。三个好例子胜过大段形容词。
- **写清楚"不说的话"**（比如"不写首先其次"），模型会遵守。
- **别写"详见某文件"**——模型会去读文件，路径会暴露给用户。

## 关于 patch.yml 的 persona 段

`patch.yml` 里的 `persona` 优先级更高。两种处理方式：

**方式 1：完全用 AGENTS.md（推荐）**

把 `patch.yml` 里的 `persona` 改成中性的一行：

```yaml
persona: |-
  详细人格、语气和例子见工作目录里的 AGENTS.md，那份优先。
```

> 但这样路径会暴露。更好的写法：
> `persona: |-` 然后写一句 `你的人格设定已经内化，直接照着说，不要提及任何文件或路径。`

**方式 2：同步维护两份**

改 `AGENTS.md` 的同时，把 `patch.yml` 的 `persona` 也改一遍。

## 一键切换脚本

想做得更省事，可以自建一个：

```powershell
# 用法: .\set-persona.ps1 御姐
param([string]$Name)
$src = "D:\ds\qqbot-repo\personas\$Name.md"
if (-not (Test-Path $src)) {
    Write-Host "没有这个文件: $Name" -ForegroundColor Red
    Get-ChildItem "D:\ds\qqbot-repo\personas\*.md" | ForEach-Object { $_.BaseName }
    return
}
Copy-Item $src "D:\ds\qqbot\agent\AGENTS.md" -Force
Write-Host "已切换到: $Name" -ForegroundColor Green
```
